# FINL 재정 연계 인터페이스 — 소스 (가상)

`apps/legacy-pps` 의 FINL(:18003) 이 구축 당시 이런 모양이었다고 가정한 **시연용 가상 소스**다.
2015년 전자정부 표준프레임워크(Spring MVC + MyBatis) 구조를 따른다.

FINL 은 기계가 읽는 명세(OpenAPI · WSDL)가 없고 인터페이스정의서(xlsx)만 있다. 온보딩 위자드의 **소스 코드** 채널이
이 디렉터리를 읽어 URL 매핑 → 서비스 → 매퍼 SQL 까지 따라가 읽기 · 쓰기를 판정하고, 서버 주소(:18003)가 있으면
읽기 API 를 한 번씩 불러 실재를 대조한다.

정의서의 `ACNT_DIV_CD`(회계구분코드)는 매퍼 SELECT 에 없다. 정의서보다 소스가 사실에 가깝다는 것을 보여 주는 매설 결함이다.
