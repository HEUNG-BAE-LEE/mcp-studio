# 이음 관리 콘솔 (web/ieum)

AI 프로토콜 변압기 "이음"의 관리 콘솔입니다. 바닐라 JS, 빌드 단계 없음.
백엔드(FastAPI, `apps/backend/app/ieum`)가 `/ieum/` 에서 정적 서빙하고, 모든 데이터는 `/api/ieum/<메뉴>/` JSON API로 주고받습니다.
화면이 API를 상대 경로로 부르므로 **백엔드와 같은 주소에서 열어야** 합니다. 파일을 따로 서빙하면 동작하지 않습니다.

| 메뉴 | 화면 JS | 백엔드 라우터 (`app/ieum/routers/`) | 하는 일 |
|---|---|---|---|
| 대시보드 | `js/menu/dashboard.js` | `dashboard.py` | 호출 로그에서 KPI, 시간대별 호출, 많이 쓰인 도구 계산 |
| 원본 시스템 | `js/menu/sources.js`, `js/menu/discovery.js` | `sources.py`, `discovery.py` | OpenAPI/WSDL/호출 샘플/공공데이터 명세를 읽어 시스템 등록, 도구 후보 생성, 명세 재읽기(변경 감지), 삭제. 명세가 없으면 **API 자동 탐색** |
| 변환 스튜디오 | `js/menu/studio.js` | `studio.py` | 도구 설명, 파라미터·응답 매핑, 변환 규칙, 실행 정책 편집. "AI로 다시 쓰기"는 GPT(백엔드의 `AZURE_OPENAI_*`)가 도구 설명을 새로 씁니다 |
| 테스트 실행 | `js/menu/playground.js` | `playground.py` | 도구를 실제로 호출해 원본 요청, 응답, 변환 결과를 단계별로 확인. 자연어 질문은 `ANTHROPIC_API_KEY` 필요 |
| AI 연결 배포 | `js/menu/deploy.js` | `deploy.py` + `runtime/` | 도구 묶음 구성, 액세스 키 발급, **MCP 서버 배포**(묶음마다 이 컴퓨터에 프로세스로 뜸. 아래 "배포") |
| 호출 로그 | `js/menu/logs.js` | `logs.py` | MCP·테스트 실행의 모든 호출 기록과 변환 과정 |

공통 코드는 `js/common/`(상태, 유틸, 변환 과정 표시, API 호출), 진입점은 `js/main.js`.
백엔드 구조는 `apps/backend/app/ieum/__init__.py` 의 설명을 보세요. 게이트웨이 핵심(명세 파싱, 변환 엔진, 인증 보관, 실행)은 `gateway/`, 시연용 원본 시스템은 `routers/demo_origin.py`.

## 실행

저장소 루트에서 한 번에 띄웁니다. 이음은 백엔드 프로세스에 함께 올라가므로 따로 띄울 것이 없습니다.

```bash
./start.sh
# http://localhost:8000/ieum/
```

의존성(PyYAML, cryptography)은 `apps/backend/requirements.txt` 에 있습니다. `start.sh` 가 불러오지 못하면 알려 줍니다.

## API 자동 탐색

명세가 없는 레거시 시스템에서 API 를 찾습니다. 연결 방식에서 **API 자동 탐색**을 고르면 세 단계(연결 방식, 탐색 대상, 안전 설정)를 거쳐 탐색이 시작되고, 진행 과정이 실시간으로 보입니다.
탐색 대상 단계에서 **탐색 목적**(예: 구매팀 업무를 AI 비서로 조회)과 AI 비서가 받을 **질문 예시**를 적습니다(둘 다 필요합니다). 이음은 이것을 보고 메뉴를 열 순서를 정하고, 찾은 API 가 어떤 질문에 답하는지 잇습니다.
안전 설정 단계에서는 크롤러가 판단하기 어려운 곳에서 사람에게 **물어볼지**(애매할 때만 / 새 화면마다 / 묻지 않고 건너뛰기)와, 답이 없을 때 **몇 분 뒤 안전한 쪽으로 처리할지**를 고릅니다. 야간 예약 탐색에는 "묻지 않고 건너뛰기"가 맞습니다(API 로 시작할 때 `hitl` 를 생략하면 이쪽입니다).

- **운영 화면 탐색.** 헤드리스 브라우저가 서비스 계정으로 로그인해 메뉴를 돌며 버튼을 누르고, 화면이 부르는 요청과 응답을 캡처합니다.
  브라우저는 번들 Chromium 이 없으면 이 PC 에 설치된 Chrome(또는 Edge)을 씁니다. 둘 다 없을 때만 `.venv/bin/python -m playwright install chromium` (약 170MB)이 필요합니다.
  **Apple 실리콘에서 x86_64 Python(Rosetta)으로 서버를 띄우면 Chrome 도 변환되어 떠서 자바스크립트가 5~10배 느립니다.** 스크립트가 무거운 사이트(실측: wehago.com 은 네이티브 4초, 변환 30초 초과)는 시작 화면이
  시간 초과로 열리지 않습니다. 그래서 이런 PC 에서는 설치된 Chrome·Edge 를 `arch -arm64` 로 감싸 **네이티브로 먼저** 띄우고(화면에 `chrome (네이티브)` 로 보입니다), 안 되면 예전 방식으로 돌아갑니다.
  번들 Chromium 만 있고 Chrome·Edge 가 없다면 변환된 채로 떠서 느립니다 — Chrome 을 설치하거나 arm64 Python 으로 venv 를 다시 만드세요.
- **Git 소스 분석.** 저장소를 읽어 컨트롤러의 URL, 파라미터, 읽기/쓰기를 찾습니다. Spring MVC·전자정부(MyBatis/iBatis 까지 호출 사슬을 따라가 SELECT/INSERT/UPDATE 로 읽기·쓰기를 판정), Express, FastAPI, Flask 를 지원합니다.
  AST 가 아니라 구문을 읽는 스캐너라서, 못 따라간 것은 "미확인"으로 표시하고 지어내지 않습니다.
- **교차 확인.** 두 근거를 경로로 맞춰 "모두 확인 / 소스에만 / 트래픽에만"으로 나눕니다. 값만 다른 요청은 경로 하나로 묶고, 공통코드 응답이 있으면 코드값 변환표를 만들어 파라미터와 응답 필드에 붙입니다.
- **호출 검증.** 읽기로 **증명된** API 만 운영에 한 번씩 다시 부릅니다. 쓰기는 사용자가 스테이징 주소를 줬을 때만 스테이징에서 시험 값으로 부릅니다.
- **등록.** 고른 API 를 도구 후보로 등록합니다. 서비스 계정 로그인 방법(레시피)을 함께 저장해, 도구를 실행할 때 이음이 같은 방식으로 로그인해 세션을 받습니다. 세션이 끊기면 다시 로그인해서 한 번 더 보냅니다.
  같은 운영 주소의 자동 탐색 원본이 이미 있으면 그 원본에 합칩니다. 이미 등록된 도구는 건드리지 않고(스튜디오에서 고친 설명과 공개 상태가 남습니다) 새 도구만 더합니다.

### 사람과 함께 탐색하기

로그인한 뒤 크롤러가 왼쪽 메뉴를 읽어 목적에 맞춰 **탐색 계획**을 세웁니다(`탐색 계획` 탭). 질문에 이름이 겹치는 메뉴가 먼저이고, 관련이 낮은 메뉴는 사람에게 묻습니다. 계획은 AI(GPT)가 설정돼 있으면 AI 가,
없거나 실패하면 메뉴 이름과 질문의 낱말이 겹치는 정도로 정하며, 어느 쪽인지 화면에 보입니다. AI 에는 메뉴 이름, API 의 메서드·경로·제목·파라미터와 응답 필드 **이름**, 목적과 질문만 보내고 응답 값과 인증 정보는 보내지 않습니다.

크롤러는 판단하기 어려운 곳에서 **질문을 남기고 기다리지 않습니다.** 다른 메뉴를 계속 탐색하다가, 답이 나오면 그 답대로 그 화면에 돌아와 처리합니다. 질문은 한 번에 하나만 **질문한 순간의 화면** 위 카드로 뜨고,
시간은 그 질문에만 흐릅니다(카드 위에 마우스를 올리면 멈춥니다). 답이 없으면 안전한 쪽으로 처리하고 그렇게 기록합니다. 다른 화면을 보고 있어도 머리글 종 아이콘과 탭 제목의 숫자로 알립니다.

| 질문 | 언제 | 안전한 기본값 |
|---|---|---|
| 위험해 보이는 버튼 | 누르지 않을 단어에는 없지만 `마감`, `취소`(이름이 "취소"뿐이면 제외), `반려`, `폐기`, `정산`, `발행` 같은 낱말이 있는 버튼 | 건너뜀. 허락하면 눌러 보되 요청은 운영에 보내지 않고 형식만 기록 |
| 입력값 필요 | 버튼이 "…을 입력하세요" 알림창을 띄울 때 | 질문 예시에 나온 이름(한빛상사)이 있으면 그 이름으로 넣어 본다, 없으면 건너뜀 |
| 권한 문제 | 화면이 403/401 이거나 "권한 없음" 안내만 보일 때 | 건너뜀. "직접 보여 줄게요"를 고르면 직접 조작 |
| 관련도 낮음 | 질문과 이름이 겹치지 않는 메뉴(최대 3개까지 묻고 나머지는 묻지 않고 건너뜀) | 건너뜀 |
| 새 화면 | "새 화면마다 묻기"일 때 처음 여는 화면 | 탐색 |

- **지시.** 입력줄에 "거래처 관리는 보지 마", "통계도 탐색해 줘", "발주 승인은 내가 보여줄게" 처럼 적으면 메뉴 이름과 건너뛰라는 말을 알아듣고 계획에 반영합니다. 그 밖의 말은 **메모로만 남긴다고 그대로 알립니다.** 제외 경로는 말로 풀 수 없습니다.
- **일시정지.** 눌러 두면 크롤러가 쉬고, 쉰 시간은 시간 상한에 넣지 않습니다.
- **직접 조작.** 헤드리스 브라우저의 화면 캡처를 눌러 사람이 직접 조종합니다(글자는 입력줄로 보냅니다). 권한 문제 질문에서 시작하면 테스트 계정의 세션을 잠시 비우고 **로그인 화면에서 시작**해, 권한 있는 사람이 자기 계정으로 로그인해 보여 줄 수
  있습니다. 끝내면 세션을 되돌려 테스트 계정으로 이어서 탐색하고, 그 화면에서 하던 일도 이어서 합니다. 사람이 입력한 글자는 어디에도 저장하지 않습니다. 이때 찾은 API 는 결과에 **사람 확인**으로 표시됩니다.
- **용도 기입.** 요청 줄과 결과 표의 연필 아이콘으로 API 의 용도와 답하는 질문을 고칩니다. 결과 검토, 도구 후보의 설명 초안(`"…" 같은 질문에 답할 때 씁니다.`)에 그대로 쓰입니다.
- **결과.** 질문 예시별 커버리지(답할 API 를 찾았는지), 용도 열, 사람 확인 표시와 필터, "사람과 함께 탐색했습니다" 요약(쓰기 차단, 사람 결정, 자동 처리한 질문 수)이 나옵니다. 용도와 질문 연결은 AI 가 없으면 이름이 겹치는 정도로 **추정**한 것이라
  표시가 다르고, 쓰기 API 는 이름이 겹친다고 잇지 않습니다. 틀리면 연필로 고치세요.

### 안전

운영 시스템에 닿는 기능이라 두 겹으로 막습니다.

1. **무엇을 누를지 고를 때.** 누르지 않을 단어(기본: 삭제, 저장, 승인, 결재, 결제, 확정, 전송), 제외 경로, 로그아웃, 삭제처럼 보이는 주소는 건너뜁니다. 표의 데이터 행은 단어 검사에서 뺍니다.
2. **브라우저가 요청을 보낼 때.** POST/PUT/PATCH/DELETE 는 전부 가로채 **운영에 보내지 않고** 형식만 기록합니다. 로그인 요청과, 마법사에서 "조회용 POST"로 지정한 경로만 예외입니다.
   1번을 비워도(금지어 목록 삭제) 2번이 남으므로 쓰기가 운영에 닿지 않습니다. 이 점은 테스트(`test_누르지_않을_단어를_모두_빼도_쓰기는_운영에_닿지_않는다`)로 고정돼 있습니다.

사람이 눌러도 된다고 한 버튼, 사람이 직접 조작한 승인도 2번은 그대로입니다. 눌러 보는 동안에는 **화면 이동(GET)도 막고**(쓰기를 GET 링크로 구현한 화면이 있어도 닿지 않게), 직접 조작에서 풀어 주는 것은 로그인 요청뿐입니다.
이 점은 서버 데이터로 확인합니다(`test_ieum_discovery_hitl.py`: 마감 처리와 승인을 사람이 해도 마감된 구매요청과 승인 대기 건수가 그대로).

실시간 탐색 화면의 브라우저 캡처는 픽셀이라 마스킹할 수 없습니다. 메모리에만 두고 파일로 저장하지 않지만, 콘솔에 접속한 사람은 탐색 중에 그 화면을 볼 수 있습니다. 소스 근거의 코드 조각에서는 `password = "..."` 같은 비밀 리터럴을 가립니다.

소스 분석은 별도 프로세스에서 시간 제한(120초)을 두고 돌려, 악의적으로 만든 저장소가 서버를 붙잡지 못하게 합니다. 저장소 안의 심볼릭 링크는 따라가지 않습니다.

그 밖에: 한 번에 하나의 탐색만 돌고, 운영 서버에는 요청 사이 0.6초 이상 간격을 둡니다(로컬은 예외). 캡처한 전화번호·사업자번호·주민번호·카드번호·이메일은 저장 전에 가리고, 비밀번호·토큰·쿠키는 항상 가립니다.
계정 비밀번호와 Git 토큰은 작업 설정에 남기지 않고 암호화 금고(`source_secrets.enc`)에만 둡니다. 시작할 때 운영 시스템 담당자의 승인을 확인하며, 시각을 예약할 수도 있습니다(서버가 켜져 있어야 시작합니다).

### 시연용 값

이 서버에는 시연용 구매관리 레거시 사이트(`/demo-legacy/po`, 스테이징 `/demo-legacy/po-stg`)와 그 Java 소스 샘플(`app/ieum/demo_legacy/po-web`)이 들어 있습니다.
연결 마법사 2단계의 **시연용 값 채우기**를 누르면 주소, 계정(`svc_ieum_crawl` / `demo-pass`), 소스 경로가 채워집니다. 실제 시스템이 아니라 시험용 가짜입니다.

### 서버가 읽는 로컬 폴더

저장소 칸에는 `https://` 주소 외에 서버의 폴더 경로도 쓸 수 있지만, 서버가 아무 폴더나 읽으면 안 되므로 **허용한 폴더만** 읽습니다. 번들된 시연용 소스 외에는 `IEUM_LOCAL_REPO_ROOTS` 에 상위 폴더를 적어야 합니다.

## 배포 (MCP 서버)

**배포하기**를 누르면 묶음 하나가 **MCP 서버 프로세스 하나**로 이 컴퓨터에 뜹니다(`python -m app.ieum.runtime.server`).
주소는 `http://127.0.0.1:<포트>/mcp`(포트는 8100~8199 중 처음 받은 것을 계속 씁니다), 전송은 Streamable HTTP, 인증은 발급한 액세스 키(Bearer)입니다.

- **배포는 스냅샷이다.** 배포하는 순간의 도구 정의와 연결 정보가 `data/ieum/deployments/<묶음 id>/manifest.json` 에 얼려 들어가고, 서버는 그 파일만 봅니다.
  스튜디오에서 설명을 고치거나 공개를 꺼도 **새 버전을 배포하기 전에는 서버에 닿지 않습니다.** 인증 정보는 스냅샷에 없고, 서버가 호출할 때 금고에서 읽습니다.
- **스튜디오의 공개 설정은 저장해야 서버가 압니다.** "공개"는 화면에서 켜기만 하면 브라우저에만 있고, "변경사항 저장"을 눌러야 서버에 갑니다. 배포 창은 저장하지 않은 도구가 있으면 먼저 저장하고 배포합니다.
- **새 버전 배포는 서버를 다시 띄우지 않습니다.** 떠 있는 프로세스가 다음 요청부터 새 스냅샷으로 답하므로 연결된 AI 앱이 끊기지 않습니다(`v1.0` → `v1.1`). 새 스냅샷을 서버가 읽지 못하면 배포가 실패하고 이전 버전이 그대로 서비스됩니다.
- **시작·중지·로그.** 화면에서 서버를 중지하고 같은 버전·같은 주소로 다시 시작할 수 있습니다. 서버 로그(`deployments/<묶음 id>/server.log`)는 "서버 로그"에서 봅니다. 서버가 죽으면 화면에 "비정상 종료"로 보입니다.
- **콘솔과 함께 움직입니다.** 콘솔(백엔드)이 내려가면 서버도 내려가고(강제 종료돼도 서버가 1초쯤 뒤 스스로 끝나 포트가 남지 않습니다), 콘솔이 다시 뜨면 배포 중이던 묶음을 **같은 스냅샷, 같은 포트로** 다시 띄웁니다. 사람이 중지한 묶음은 올리지 않습니다.
- **키는 바로 막힙니다.** 서버는 호출마다 키 저장소를 읽으므로 키를 폐기하면 다시 띄우지 않아도 그 순간부터 401 입니다. 호출 기록은 콘솔의 호출 로그에 같이 쌓입니다.

연결 예(같은 컴퓨터의 Claude Code):

```bash
claude mcp add --transport http ieum-hr http://127.0.0.1:8100/mcp --header "Authorization: Bearer <발급한 키>"
```

**한계.** 서버는 이 컴퓨터(127.0.0.1)에서만 열립니다. 같은 컴퓨터의 Claude Code, Gemini CLI 는 연결되지만 클라우드에서 도는 AI(OpenAI API, 웹 커넥터)는 이 주소에 닿지 못합니다.
브라우저가 보낸 요청은 Origin 이 이 컴퓨터가 아니면 막습니다(DNS 리바인딩). 콘솔 프로세스는 하나라고 가정합니다(`uvicorn --workers N` 이면 같은 묶음을 N 번 띄웁니다).
서버를 다른 곳(컨테이너 등)으로 옮기려면 `runtime/supervisor.py` 자리만 바꾸면 됩니다. 서버(`runtime/server.py`)는 스냅샷 파일과 상태 폴더만 있으면 돕니다.

## 바로 써 보기

시연용 레거시 인사 시스템(REST + SOAP)이 백엔드 안에 들어 있습니다.
원본 시스템 연결 → REST → 명세 URL `http://localhost:8000/demo-origin/openapi.json`, 인증 API Key(헤더 `X-API-KEY`, 값 `demo-key`).
SOAP은 `http://localhost:8000/demo-origin/hr.wsdl`, 인증 없음.

연결 후: 변환 스튜디오에서 검토 후 공개(**변경사항 저장**까지) → AI 연결 배포에서 묶음 만들기, 배포, 키 발급 → 발급된 키로 MCP 연결.

```bash
# 주소는 배포 화면의 "MCP 서버 주소" 입니다
curl http://127.0.0.1:8100/mcp -H "Authorization: Bearer <키>" \
  -H "Content-Type: application/json" -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

## 환경변수

`apps/backend/.env` 에 적으면 됩니다. 모두 선택입니다.

| 이름 | 용도 |
|---|---|
| `AZURE_OPENAI_ENDPOINT`, `AZURE_OPENAI_API_KEY`, `AZURE_OPENAI_API_VERSION`, `AZURE_OPENAI_DEPLOYMENT` | 변환 스튜디오 "AI로 다시 쓰기"가 부르는 GPT. LLM 콘솔이 쓰는 값과 **같은 것**이라 이미 `.env` 에 있으면 따로 할 일이 없습니다. `DEPLOYMENT` 는 모델 이름이 아니라 배포 이름 |
| `ANTHROPIC_API_KEY` | 테스트 실행의 자연어 질문(Claude). "AI로 다시 쓰기"는 위 GPT 설정이 없을 때만 이걸로 Claude 를 부릅니다. 둘 다 없으면 해당 기능만 꺼짐 |
| `IEUM_CHAT_MODEL` | Claude 를 쓸 때의 모델 (기본 `claude-sonnet-5-5`). GPT 는 배포 이름이 정한다 |
| `IEUM_SECRET_KEY` | 원본 시스템 인증 정보를 암호화하는 키. 없으면 처음 쓸 때 무작위로 만들어 `.secret_key` 에 둡니다 |
| `IEUM_STATE_DIR` | 변경분을 저장할 폴더 (기본 `apps/backend/data/ieum`) |
| `IEUM_WEB_ROOT` | 콘솔 정적 파일 위치 (기본 `apps/web/ieum`) |
| `IEUM_LOCAL_REPO_ROOTS` | 자동 탐색이 폴더 경로로 읽을 수 있는 상위 폴더들 (경로 구분자 `:` 로 여러 개). 시연용 소스는 항상 허용 |
| `IEUM_MCP_PORTS` | 배포한 MCP 서버가 쓸 포트 범위 (기본 `8100-8199`). 쓰는 중인 포트는 건너뜁니다 |
| `IEUM_MCP_HOST` | 배포한 MCP 서버가 열 주소 (기본 `127.0.0.1`). 바꾸면 같은 네트워크에 노출되니 키 관리에 유의 |
| `IEUM_MCP_AUTORESTORE` | `0` 이면 콘솔이 뜰 때 배포 중이던 서버를 다시 띄우지 않습니다 (테스트가 쓴다) |
| `IEUM_MCP_ALLOWED_ORIGINS` | 로컬 외에 허용할 브라우저 Origin (쉼표로 구분) |

## 데이터

각 메뉴의 시드는 `apps/backend/app/ieum/data/<메뉴>/*.json` 이고 대부분 빈 초기값입니다. 실제 데이터는
`apps/backend/data/ieum/<메뉴>.<이름>.json` 에 저장됩니다(`apps/backend/data/` 는 git 제외).
원본 시스템 인증 정보는 `source_secrets.enc` 에 Fernet으로 암호화해 저장하고, 액세스 키는 해시만 저장합니다.
저장소 구현은 `app/ieum/store.py`.

초기화하려면 `apps/backend/data/ieum` 을 지웁니다. `.secret_key` 와 `source_secrets.enc` 는 짝이라
**하나만 지우면 저장된 인증 정보를 읽지 못합니다.** 지우려면 폴더째 지우세요.

## 테스트

```bash
cd apps/backend && .venv/bin/pytest tests/test_ieum_*.py -v
```

배포 시험(`test_ieum_deploy.py`)은 진짜 서버 프로세스를 띄워 배포, 새 버전, 중지·시작, 강제 종료, 콘솔 재시작 복구까지 확인하고 20초쯤 걸립니다.
자동 탐색의 전 구간 시험(`test_ieum_discovery_e2e.py`)은 실제 헤드리스 브라우저로 시연용 사이트를 탐색해서 2분쯤 걸립니다. 사람과 함께 탐색하기(`test_ieum_discovery_hitl.py`, 계획·질문·지시·일시정지·직접 조작·시간 초과·취소)는
5분쯤 걸리고, 직접 조작은 좌표로 로그인부터 승인 버튼까지 누릅니다. 규칙 시험(`test_ieum_hitl.py`)은 브라우저 없이 1초 안에 끝납니다. 브라우저가 없거나 `IEUM_SKIP_BROWSER_TESTS=1` 이면 브라우저 시험은 건너뜁니다. 시험은 실제 모델을 부르지 않습니다.

테스트는 상태 파일을 임시 폴더로 돌려 쓰므로 `data/ieum` 을 건드리지 않습니다.

## 아직 시연 수준인 부분

- **API 자동 탐색**은 로그인 폼(아이디·비밀번호) 방식의 시스템만 다룹니다. SSO, OTP, 캡차는 사람이 넘겨야 해서 지원하지 않습니다. 주소를 JavaScript 로만 만드는 화면, 마우스를 올려야 열리는 메뉴는 못 찾을 수 있습니다.
  쓰기 API 는 형식(파라미터)만 추론하고, 실제 동작은 스테이징 검증을 켠 경우에만 확인합니다. 도구 이름·설명·응답 필드 이름은 규칙으로 만든 초안이라 변환 스튜디오에서 다듬어야 합니다(AI 로 다시 쓰기 가능).
  메뉴는 링크(`<a href>`)로 된 것만 계획에 올립니다. 메뉴가 `javascript:` 나 `onclick` 뿐이면 계획에는 없고, 화면의 버튼처럼 눌러 보는 방식으로만 찾습니다. 직접 조작은 화면을 누르는 좌표와 글자를 보내는 방식이라 드래그, 마우스를 올려야 열리는 메뉴, 한글 조합 입력은 지원하지 않습니다.
- 응답 캐시 설정은 저장만 하고 아직 적용하지 않습니다.
- 워크스페이스, 사용자, 인증(관리 콘솔 로그인)은 없습니다. `app/ieum/data/sources/workspace.json` 의 값을 씁니다.
  콘솔 API(`/api/ieum`)와 시연용 원본(`/demo-origin`)은 인증 없이 열려 있고, 원본 시스템 연결은 서버가 입력한 주소로 직접 요청을 보냅니다.
  로컬 시연용이라는 전제이므로 외부에 공개된 서버에 올리기 전에 인증을 먼저 붙여야 합니다.
