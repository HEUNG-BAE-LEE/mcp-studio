# 내레이션 원고 — 제출 영상 (MiniMax TTS 용)

`docs/demo-script.md` 의 장면 14개에 대응한다. **장면 번호가 그 대본과 같다.**

## MiniMax 에 넣기 전에

- **장면마다 따로 생성한다.** 통으로 만들면 한 문장 고칠 때 전체를 다시 만들어야 하고,
  장면별 길이를 맞출 수 없다.
- 파일 이름을 `s01.mp3` … `s14.mp3` 로 저장하고 `docs/narration/` 에 둔다.
  그 이름을 전제로 결합 스크립트를 만든다.
- **속도는 기본(1.0)** 으로 둔다. 목표 초는 4.8음절/초 낭독 기준으로 잡았다.
  1.2배로 만들면 화면이 못 따라온다.
- 원고에 **쉼표와 마침표를 그대로 둔다.** MiniMax 가 그 자리에서 숨을 쉰다.

## 읽는 방식 확인이 필요한 낱말

TTS 가 영문 약어를 어떻게 읽는지 **한 장면을 먼저 만들어 들어 보고** 정한다.
어색하면 괄호 안 한글로 바꿔 넣는다.

| 원고 표기 | 기대 발음 | 어색하면 |
|---|---|---|
| API | 에이피아이 | `에이피아이` 로 직접 표기 |
| MCP | 엠씨피 | `엠씨피` |
| LLM | 엘엘엠 | `엘엘엠` |
| XML | 엑스엠엘 | `엑스엠엘` |
| PDF | 피디에프 | `피디에프` |

**숫자는 원고에 넣지 않았다.** "이백 밀리초" 같은 값은 TTS 가 흔들리고, 대본에도
"시간을 약속하지 않는다"고 적혀 있다. 수치는 **자막과 화면**으로만 보여준다.

## 장면 1 — 문제 제기 (8초)

```
이 지도는 API로 데이터를 받아옵니다. 그 명세는 공개돼 있지 않습니다.
```

## 장면 2 — 기록 시작 (10초)

```
확장이 화면이 부르는 호출을 관측합니다. 대상 시스템의 소스코드는 한 줄도 건드리지 않습니다.
```

## 장면 3 — 클릭 한 번 → 전송 (12초)

```
확대 버튼을 한 번 누르면, 그 클릭에 딸린 백엔드 호출이 함께 잡힙니다. 기록을 끝내고 관리자로 넘어갑니다.
```

## 장면 4 — 후보 점수 (12초)

```
화면의 데이터를 실제로 나른 API가 위로 올라옵니다. 로그를 남기는 호출은 감점되어 맨 아래로 내려갑니다.
```

## 장면 5 — MCP 도구 생성 (12초)

```
파라미터가 타입과 예시값까지 채워져 있습니다. 문서를 읽은 게 아니라, 실제로 오간 값에서 추론한 것입니다.
```

## 장면 6 — 자연어 실행 (10초)

```
이제 사람 말로 부릅니다. 지금까지 모아 둔 MCP 도구 중에서 알맞은 것을 골라, 실제로 호출합니다.
```

## 장면 7 — 실행 결과 (20초)

```
LLM이 도구를 고르고 인자를 채웠습니다. 실제 API를 호출해서 돌아온 데이터로 답합니다. 오른쪽에는 무엇을 주고받았는지 그대로 남습니다. 지어낸 값이 아닙니다.
```

## 장면 8 — 자연어로 API 찾기 (22초)

```
명세만 공개하고 실행은 막아 둔 포털은 관측으로 잡히지 않습니다. 이때는 쓸 용도를 문장으로 적습니다. 시스템이 포털을 검색해서 목적에 맞는 것만 골라 체크합니다. 왜 골랐고 왜 뺐는지도 한 줄씩 답합니다.
```

## 장면 9 — 서버에서 돈다 (10초)

```
수집은 서버에서 돕니다. 이 창을 닫아도 계속 진행되고, 다시 들어오면 어디까지 됐는지 그대로 보입니다.
```

## 장면 10 — MCP 로 만들기 (8초)

```
관측으로 모았든 명세로 읽었든, 여기서부터는 똑같은 도구가 됩니다.
```

## 장면 11 — 같은 자리에서 실행 (18초)

```
방금 찾은 도구를 그대로 씁니다. 인증키는 LLM에게 넘기지 않습니다. 서버가 실행 직전에 채우고, 등록돼 있지 않으면 호출 전에 막습니다. 응답이 XML로 와도 읽어서 답합니다.
```

## 장면 12 — 셋째 경로 (12초)

```
세 번째는 문서입니다. 사내 시스템 명세서를 올리면 명세를 구조화합니다. 공공 데이터만이 아닙니다.
```

## 장면 13 — 지어내지 않는다 (16초)

```
보도자료도 올려 봅니다. 문서를 못 읽은 게 아닙니다. 읽었지만 엔드포인트가 없어서 만들지 않은 것입니다. 없는 API를 지어내지 않는 편이 더 중요합니다.
```

## 장면 14 — 마무리 (10초)

```
세 경로로 모은 것이 하나로 합류합니다. 이후 도구 변환과 실행은 수집 방식을 구분하지 않습니다.
```

## 자막 (마지막 5초, 음성 없음)

보고서 §6.4 가 요구한 항목이다. 음성으로 읽지 않고 화면에만 얹는다.

```
프로토타입 범위 — 로그인·권한 관리·MCP 표준 엔드포인트는 2차 기간 계획입니다.
```

---

## 음성을 만든 뒤에 할 일

1. `docs/narration/s01.mp3` … `s14.mp3` 로 저장한다
2. 알려 주면 내가 `ffprobe` 로 **실제 길이를 재서** 장면별 목표 초를 갱신한다
3. 그 길이에 맞춘 **녹화 지시서**(장면별 목표 초·조작 순서)를 만든다
4. 화면을 장면별로 녹화한다 (`Cmd+Shift+5`, 장면당 파일 하나)
5. 내가 `ffmpeg` 로 클립을 음성 길이에 맞추고, 자막을 얹어 최종본을 만든다

**2번이 중요하다.** TTS 길이는 원고와 정확히 비례하지 않는다 — 실제로 재서 맞춰야
화면과 음성이 어긋나지 않는다.
