# 촬영 대본 — 대회 제출 영상 (3분)

중간결과보고서 §6.4 가 정한 규격을 따른다 — **3분 이내**, 유튜브 일부공개.
보고서의 서사("소스코드를 한 줄도 수정하지 않고", **이중 역분석**)를 화면으로 증명하는 것이
이 영상의 목적이다.

**이 대본은 2026-07-30 dev(`51ea82c`) 기준이다.** UI 가 바뀌면 §확인란부터 어긋난다.
검정 테마·사이드바 6항목·화면 문구 `MCP` 가 이 시점 기준이다.

## 0. 촬영 전 준비

### 0-1. DB 리셋 (매 테이크 시작 시)

```bash
rm -f apps/backend/data/dev.db
lsof -ti tcp:8000 -sTCP:LISTEN | xargs kill
cd apps/backend && .venv/bin/uvicorn app.main:app --port 8000
```

`-sTCP:LISTEN` 을 **반드시** 붙인다. 없으면 8000번에 *접속한* 프로세스까지 잡히는데
관리자 화면을 열어 둔 Chrome 이 거기 포함된다 (실측 3개 중 2개가 Chrome). 브라우저가 통째로 닫힌다.

**리셋 직후 상태** — 2026-07-30 리허설에서 실제로 리셋해 측정했다.

| 항목 | 값 |
|---|---|
| 프로젝트 | 3개 — `국토교통부 실거래가`(#1) / `국가통계포털 KOSIS`(#2) / `공공데이터포털 오픈API`(#3) |
| MCP 도구 | 1개 — `아파트 단지 마커 조회` / `search_apartment_markers` (프로젝트 #1, ACTIVE) |
| 세션 | 1개 — 포털 명세 세션 (프로젝트 #3). #1·#2 는 세션 없음 |
| 배지 | **#3 만** 포털 배지. #1·#2 는 `kinds=[]` 로 배지가 없다 |

**프로젝트 번호가 고정이라 장면 6 의 `/projects/1/console` 이 항상 실거래가를 가리킨다.**
리허설로 프로젝트를 하나라도 만든 채 리셋을 건너뛰면 번호가 밀려 다른 프로젝트가 열린다.

### 0-2. 최종 점검 (테이크 직전)

- [ ] 관리자(:5173)·백엔드(:8000) 가 떠 있고 `http://localhost:5173/` 와
      `http://localhost:5173/projects/1/console` 이 오류 없이 열린다
- [ ] 확장을 새로 빌드했거나 `chrome://extensions` 에서 새로고침했다면
      **대상 페이지도 새로고침**한다. 이미 열려 있던 탭의 스크립트는 고아가 되어
      클릭이 하나도 잡히지 않는데, 화면에는 오류 없이 "0 클릭"만 보여 알아채기 어렵다
- [ ] `rt.molit.go.kr` 지도가 열리고 확대 버튼이 눌린다
- [ ] **`apps/backend/.env` 를 화면에 띄우지 않는다** — Azure 키가 들어 있다
- [ ] `docs/report/assets/` 캡처를 다시 딸 계획이면 이 테이크에서 함께 딴다
      (지금 보고서 캡처는 **옛 밝은 테마**라 영상과 다른 제품처럼 보인다)

### 0-3. 미리 열어 둘 탭 (3분을 맞추려면 필수)

| 탭 | 주소 |
|---|---|
| 1 | `http://localhost:5173/` |
| 2 | `https://rt.molit.go.kr/pt/gis/gis.do` |
| 3 | `http://localhost:5173/projects/3` (공공데이터포털 오픈API) |

탭 이동은 편집으로 잘라낸다. **주소를 타이핑하는 장면은 넣지 않는다.**

### 0-4. 인증키 — 없는 것을 있는 척하지 않는다

촬영은 **키를 넣은 상태**로 한다. `.env` 에 아래 둘을 채우고 백엔드를 재시작하면
`seed_credentials()` 가 프로젝트마다 필요한 키를 자동으로 채운다.

| 환경변수 | 무엇에 필요한가 |
|---|---|
| `DATA_GO_KR_SERVICE_KEY` | 공공데이터포털 API (대기질·미세먼지 등) |
| `JUSO_CONFM_KEY` | **행정안전부 도로명주소 API — 장면 12 의 "평내동87" 이 여기 걸린다** |

**2026-07-30 리허설에서 키를 넣고 장면 8~11 을 사슬로 돌려 확인했다.** `seed_credentials()`
가 프로젝트마다 필요한 키를 자동으로 채우고, 만든 MCP 도구에 그대로 연결된다.

**주의 — 키가 있어도 API 마다 활용신청 승인이 따로 필요하다.** 같은 키로
`getMinuDustFrcstDspth`(에어코리아 예보)는 **401 Unauthorized** 가 났다. 화면은 그걸
"인증 정보가 없거나 올바르지 않아"로 요약해 정직하게 알린다. **촬영 전에 쓸 API 가
승인됐는지 한 번 호출해 확인한다.**

키가 없는 상태로 찍어야 하면 장면 11 을 빼고, 대신 Playground 헤더의
`인증키 없음` 칩을 짚어 "키가 없으면 호출 전에 막습니다"(보고서 §3.3.4)를 보여준다.
그때 장면 12~13 을 각 9초씩 늘린다.

## 대사에서 쓰지 말아야 할 말

화면과 어긋나면 심사위원이 먼저 알아챈다. `#33` 에서 화면 문구가 `액션` → `MCP` 로 바뀌었다.

| 쓰지 않는다 | 지금 이름 |
|---|---|
| 액션 | **MCP 도구** |
| 테스트 콘솔 | **Playground** |
| 수집 세션 | **수집현황** |
| 수집 엔진 | **수집 방식 안내** (왼쪽 레일 아이콘) |

**약속하지 않는 것 셋** — 실측이 흔들리는 값이다.

1. **소요 시간.** LLM 요약이 전체 시간을 지배하고 편차가 크다 (152ms ~ 5,380ms)
2. **후보 순위.** `getMarker.do` 와 `getCenterLedCdPnu.do` 가 동점이라 순서가 고정되지 않는다
3. **버튼 활성 여부.** `MCP 만들기` 의 비활성 조건은 점수가 아니라 응답이 JSON 이 아닐 때다

**장면 1~14 가 전부 실측됐다.** 남은 것은 촬영 당일 승인 여부 확인뿐이다.

**측정할 때 주의.** 미리보기 응답의 후보는 `items` 키에 담기고 체크 여부는 `include` 다.
`candidates`·`selected` 로 찾으면 0개로 읽혀 "포털이 고장났다"고 오판한다 —
이번 리허설에서 실제로 그렇게 잘못 읽었고, 크롤러를 직접 호출해 보고서야 알았다.

촬영 당일 400 이 나면 먼저 볼 곳은 `services/schema_infer.py` 의 `PRESERVED_HEADERS` 다.
`services/executor.py` 는 거기에 User-Agent·Accept 기본값만 채운다.

## 감지가 실패하면

장면 8~11 은 `data.go.kr` 의 화면 구조에 의존한다. 포털이 바뀌면 검색·파싱이 실패한다.
테이크 직전에 한 번 돌려 보고, 실패하면 그 구간을 빼고 **장면 12~13(문서 경로)을 늘린다.**
문서 경로는 저장소 안의 PDF 만 쓰므로 외부 변수가 없다. 그때 장면 14 의 대사를
"두 경로로 모은 것이" 로 줄인다.

확장의 단건 명세 수집(`공개 명세 페이지 감지`)을 대신 쓸 수도 있다. 판정 기준은 페이지에
`요청주소` 가 있고 `요청변수` 표가 함께 있는 것이다 (`apps/extension/lib/spec-detect.ts`).

## 시연용 문서 4개

`examples/documents/` 에 있다. 성공 2개와 실패 2개가 **의도적으로** 섞여 있다 —
장면 13 의 "지어내지 않는다"를 증명하는 세트다.

2026-07-30 리허설에서 넷 다 올려 측정했다. **기대대로 동작한다.**

| 파일 | 결과 | 소요 |
|---|---|---|
| `01_기상청_단기예보조회서비스_활용가이드.pdf` | **API 2개** | 9초 |
| `02_사내_회의실예약_API_명세서.pdf` | **API 3개** | 8초 |
| `03_보도자료_공공데이터_개방계획.pdf` | 0개 — "엔드포인트와 요청 변수가 적힌 문서인지 확인해 주세요" | 2초 |
| `04_국토교통부_건축물대장_활용가이드(스캔본).pdf` | 0개 — "PDF 에서 글자를 찾지 못했습니다. 스캔 이미지 문서라면 텍스트 문서로 변환해 주세요" | 0초 |

**장면 12 는 `docs/사내_회의실예약_API_명세서.pdf`(= `examples/documents/02_...` 와 동일 파일,
md5 일치)를, 장면 13 은 `03_보도자료` 를 쓴다.** 사내 명세서를 쓰면 "공공만이 아니다"가
한 장면에서 함께 증명된다 — 보고서 §7.1 의 B2B 시장 서술과 이어진다.

`03` 이 중요하다. 서비스명은 **읽어냈다** — `2026년 하반기 공공데이터 개방 확대 계획`.
읽지 못해서 못 만든 게 아니라 **읽고 나서 만들지 않기로 한 것**이다. 장면 13 의 대사는
이걸 짚어야 한다: "문서를 못 읽은 게 아닙니다. 읽었지만 엔드포인트가 없어서 만들지
않은 것입니다."

`04` 는 성격이 다르다 — 글자 자체가 없어서(스캔 이미지) 0초에 멈춘다. 같은 "0개"지만
이유가 다르고, 화면이 그 차이를 말한다. 시간이 남으면 셋을 나란히 올려 세 갈래를
한 화면에서 보여줄 수 있다.
